# Design Provenance

Researchstack is independently written for computer systems, networking, and AI paper workflows. Version 0.3 studied the following public skill packs and adapted selected workflow ideas without copying their prompts, runtime, or hooks:

- [K-Dense scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills): keeping observations, hypotheses, mechanisms, predictions, rivals, and evidence distinct; using discriminating predictions rather than treating a plausible mechanism as proof.
- [Orchestra AI-Research-SKILLs](https://github.com/Orchestra-Research/AI-Research-SKILLs): exploring a problem through multiple ideation lenses and separating problem-first from solution-first reasoning.
- [ARS-Codex](https://github.com/Imbad0202/academic-research-skills-codex): traceable source coverage, material provenance, and explicit claim-promotion gates.
- [SNL-UCSB paper-writing-skill](https://github.com/SNL-UCSB/paper-writing-skill): separating argument planning, drafting, evaluation, revision, and compression; using section-specific rhetorical moves.

Researchstack retains its own systems-specific rules:

- established solutions are audited before a new mechanism is proposed,
- topic saturation and method novelty are judged separately,
- the real semantic unit and deployment lifecycle remain inside the comparison boundary,
- a fixed topic is preserved while alternative methods are generated,
- shared infrastructure does not count as a repeated contribution across papers.

These upstream projects remain separate dependencies only when a user explicitly installs or invokes them. Researchstack v0.3 does not bundle their code, network services, hooks, or external runtimes.
